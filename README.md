= Laboratorio 09 BD2

1. Instale todas las librerías necesarias con `pip install -r requirements.txt`.
2. Inserte el `.env` en la raíz del repositorio. Asegúrese que en la DB en cuestión, los .csv estén cargados
a tablas llamadas `noticias` y `stopwords` respectivamente.
3. Ejecute `preprocessing.py` para actualizar los bag of words a la columna `bag_of_words` en `noticias`.
